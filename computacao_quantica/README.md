# Computação Quântica e IA — Global Solution 2026.1

**Integrantes:** William Stahl Sanches Furquim Garcia (RM 562800) | Paulo Gabriel Pessoa da Silva (RM 566446)

## Sobre o módulo

Aplicação de Quantum Machine Learning (QML) com Qiskit 1.x para classificação de dados de monitoramento ambiental.
Algoritmos implementados: QSVC (Quantum Support Vector Classifier) e VQC (Variational Quantum Classifier).
Comparação com baselines clássicos: SVM e Random Forest, usando AUC-ROC, F1-score e tempo de treinamento.
