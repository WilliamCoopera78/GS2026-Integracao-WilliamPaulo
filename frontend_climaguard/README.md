## Sobre o módulo

Dashboard interativo de monitoramento de desastres climáticos desenvolvido em Streamlit.
Apresenta dados de enchentes, secas, deslizamentos e ciclones com filtros interativos,
gráficos Plotly e mapa de calor por região.
