## Sobre o módulo

Sensor neuromórfico embarcado para monitoramento de condições críticas em rover lunar autônomo.
Monitora temperatura, radiação e poeira lunar. Emite eventos discretos (normal / observação / alerta crítico).
Processamento local (edge computing) — apenas transições de estado são transmitidas.
