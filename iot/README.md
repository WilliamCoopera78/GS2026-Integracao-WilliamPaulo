## Sobre o módulo

Coleta de dados ambientais em tempo real com ESP32.
- Sensores: DHT22 (temperatura/umidade), LDR (luminosidade), higrômetro (umidade do solo)
- Simulação: Wokwi
- Protocolo: MQTT → broker HiveMQ
- Automação Node-RED: `flows.json`
