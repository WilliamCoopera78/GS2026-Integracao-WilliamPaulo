## Sobre o módulo

Classificador de imagens de satélite para detecção de risco de incêndio florestal.
- Dataset: Wildfire Prediction Dataset (Kaggle) — ~42 mil imagens (Wildfire / No Wildfire)
- Modelo: EfficientNetB0 com transfer learning e fine-tuning
- Ambiente: Google Colab com GPU T4
